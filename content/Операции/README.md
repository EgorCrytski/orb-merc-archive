# ОПЕРАЦИИ

Раздел содержит вводные материалы для группы, которую планируется направить в ЧЗО.

В папке «ЧЗО - вводные материалы» размещены:

- предварительный информационный брифинг;
- хронологическая справка;
- справка о группировках и сторонах;
- служебное описание группы: обозначение, профиль, порядок работы, задача.

Параметры предстоящей операции, маршрут, заказчик и приказ о выдвижении не определены.
