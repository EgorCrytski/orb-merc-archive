# ЛИЧНЫЕ ДЕЛА

Учётные карточки пяти участников группы. Каждый участник — отдельная папка:

- `Эхо/`
- `Крюгер/`
- `Леший/`
- `Терапевт/`
- `Дрезден/`

Внутри папки лежат:

- `dossier.md` — учётный файл;
- изображения — `mugshot.png` и другие материалы по этому человеку, рядом с файлом.

Структура расширяемая. Новая папка с `dossier.md` и картинками индексируется сборкой автоматически: скан рекурсивный, тип записи определяется расширением, правок в коде это не требует.

Карточки заполнены по состоянию на 16.10.2015. Состав разделов: идентификация, правовой статус, пригодность, хронология, характер, оценка HQ, примечания.
